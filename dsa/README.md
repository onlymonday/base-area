# 数据结构与算法

> 手撕代码环节的弹药库。目标是高频题肌肉记忆，不是刷完力扣。

## 知识地图

### 线性结构

- 数组与链表（反转、合并、环、相交）
- 栈与队列（单调栈、单调队列）
- 哈希表（冲突解决、设计题）

### 树

- 二叉树的遍历（递归 / 迭代 / Morris）
- 二叉搜索树、平衡树（AVL / 红黑树的概念）
- 堆与优先队列（TopK 问题）
- B 树 / B+ 树 / LSM 树（结合数据库一起理解）
- Trie（前缀树）

### 图

- BFS / DFS、拓扑排序
- 并查集

### 算法思想

- 二分查找（边界变体）
- 双指针、滑动窗口
- 回溯
- 动态规划（背包、子序列、区间 DP）
- 贪心

### 高频手撕清单

- LRU / LFU 缓存
- 快速排序及其变体
- K 个一组翻转链表
- 三个线程交替打印 ABC
- 生产者消费者（多语言实现）
