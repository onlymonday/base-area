# 安全

> 后端面试的安全题不多但致命——答不上会直接暴露工程短板。

## 知识地图

### Web 安全

- SQL 注入：原理与防御（预编译、参数校验）
- XSS：存储型 / 反射型 / DOM 型，转义与 CSP
- CSRF：Token、SameSite Cookie
- SSRF、文件上传漏洞
- 越权：水平越权与垂直越权

### 加密与签名

- 对称加密与非对称加密、混合加密
- 哈希与加盐、密码存储的正确姿势（bcrypt / argon2）
- 数字签名与证书体系

### 认证与鉴权

- Session vs JWT：状态、注销、续期的取舍
- OAuth2 四种授权模式
- SSO 与 CAS
- RBAC 权限模型

### 其他

- 防重放攻击（nonce + timestamp）
- 风控与防刷：频控、验证码、设备指纹
- 敏感数据治理：脱敏、加密存储

## 面试高频考点

3. OAuth2 的四种模式分别适用什么场景？
4. 用户密码在数据库里应该怎么存？
