# AI 工程

> 传统后端 + AI 应用是当前最明显的技能溢价方向。本模块关注工程落地，不卷论文。

## 知识地图

### LLM 应用开发

- Transformer 基础结构、注意力机制（面试会问，但不用会推导）
- Token、上下文窗口、温度等核心参数
- Function Calling / 结构化输出
- 应用架构：对话管理、多模型路由、降级与成本控制
- 效果评估：如何量化一个 LLM 应用的好坏

### RAG（检索增强生成）

- 文档加载与切分（chunking 策略）
- Embedding 与向量检索、混合检索（BM25 + 向量）
- 重排（rerank）与引用溯源
- 效果评估与常见优化手段

### Agent

- 工具调用与规划（ReAct 等）
- 记忆管理：短期上下文与长期记忆
- 多 Agent 协作
- MCP 等协议与工具生态

### Prompt 工程

- Few-shot、思维链（CoT）
- 结构化输出约束
- Prompt 的版本管理与评测

### 模型推理与微调

- 推理优化：KV Cache、量化、批处理（vLLM 等）
- 微调路径：SFT、LoRA，什么时候微调、什么时候 RAG

## 面试高频考点

1. RAG 和微调怎么选？
2. RAG 效果差，从哪些环节排查优化？
3. Agent 和普通工作流的区别是什么？
4. 大模型幻觉是什么，工程上如何缓解？
5. 向量数据库怎么选型？为什么向量检索快？
6. 如何控制 LLM 应用的成本？
