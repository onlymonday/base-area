# AI 工程 · 面试题

本目录收录「AI 工程」相关的面试题。

## 收录标准

- 一题一文件，文件名使用中文（可含英文缩写，不用空格），如 `MySQL为什么用B+树索引.md`
- 每题四段式：一句话结论（可判断）、机制原理（带图或表）、典型错误答案（原话 + 机制）、追问（应答思路）
- 使用 [面试题模板](../../docs/templates/question-template.md) 编写
- 「怎么设计一个 AI 系统」类场景题在 [AI 场景题地图](../../system-design/questions/ai/README.md)，与本目录互为表里
