# 面试软技能与职业发展

> 技术好不代表 offer 好。这里沉淀"人的环节"：从简历到入职，再到晋升。

## 知识地图

### 简历

- 项目描述的写法：STAR 结构、量化成果、突出决策而非罗列技术
- 关键词与 JD 的匹配
- 常见扣分项：流水账、堆砌技术名词、无量化

### 项目深挖应对

- 技术难点怎么提炼：难点 = 约束 + 取舍 + 结果
- 被追问细节时如何应对（不会就诚实，给出推理路径）
- 如何把平凡项目讲出不平凡的思考

### 面试流程

- 自我介绍：结构与时长控制
- 一面 / 二面 / 三面 / HR 面各自的考察点
- 反问环节：问什么显水平

### HR 面与谈薪

- 常见问题应对：离职原因、职业规划、优缺点
- 薪资结构与报价策略
- 多 offer 对比框架：现金、成长、风险、平台
- 背调与入职注意

### 职业发展

- 晋升述职：怎么讲价值、怎么准备答辩
- 学习方法：如何建立个人知识体系（本仓库就是一种实践）
- 技术人副业与开源参与

## 常见问题

1. 自我介绍怎么准备？
2. 项目难点被深挖到答不上怎么办？
3. 离职原因怎么说才不踩雷？
4. 怎么谈薪资？期望薪资报多少合适？
5. 拿到两个 offer 怎么选？
