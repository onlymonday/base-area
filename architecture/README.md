# 架构设计

> 从"会用"到"会设计"。系统设计题（system-design）考单题，这里沉淀通用方法论。

## 知识地图

### 微服务

- 拆分原则：按业务能力、团队规模（康威定律）、拆分粒度的权衡
- 服务治理：注册发现、负载均衡、超时与重试风暴
- 熔断 / 限流 / 降级：计数器、漏桶、令牌桶算法对比
- 分布式链路下的故障定位思路

### 高可用

- 可用性指标（几个 9）与故障预算
- 容灾：同城双活、异地多活
- 故障演练与混沌工程
- 灰度发布、蓝绿部署、滚动发布

### 高性能

- 性能优化方法论：定位 → 瓶颈分析 → 优化 → 验证
- 压测设计与性能指标（P99 为什么比平均值重要）

### 设计素养

- 设计原则（SOLID、KISS）与常用设计模式在工程中的应用
- DDD：限界上下文、防腐层
- 技术选型的方法论：什么时候不自研、什么时候造轮子

## 面试高频考点

1. 限流算法有哪些？分布式限流怎么做？
2. 微服务拆多细合适？拆错了怎么合回来？
3. 系统如何做到 99.99% 可用？
4. 线上出现偶发超时，怎么系统性排查？
